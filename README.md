# 🚀 Automated CI/CD Data Pipeline Dashboard

### **College Project Submission: DevOps & Data Automation**
This project demonstrates a complete **End-to-End Automated Pipeline** that processes CSV data and updates a live dashboard using modern DevOps tools.

---

## 📑 Project Overview
The goal of this project is to automate the ingestion, cleaning, and visualization of data. Instead of manual updates, this system uses a **CI/CD (Continuous Integration / Continuous Deployment)** approach to ensure that every code change is automatically tested, containerized, and pushed to the cloud.

---

## 🏗️ Architecture Flow (How it works)
`Local Code` ➡️ `GitHub (Push)` ➡️ `GitHub Actions (Auto-Build)` ➡️ `Docker Hub (Cloud Storage)` ➡️ `Streamlit (Live Dashboard)`

---

## 🛠️ Tech Stack & Tools
| Category | Tool Used |
| :--- | :--- |
| **Language** | Python (Pandas) |
| **Dashboard** | Streamlit |
| **Containerization** | Docker |
| **Automation (CI/CD)** | GitHub Actions |
| **Cloud Registry** | Docker Hub |
| **Version Control** | Git & GitHub |

---

## ✨ Key Features
- **Automated Pipeline:** Every `git push` triggers a new Docker build automatically.
- **Smart Data Analysis:** Upload any CSV file to see instant KPIs and Trends.
- **Cloud-Ready:** Containerized using Docker for "Run Anywhere" capability.
- **Interactive UI:** Professional and attractive dashboard for data insights.
